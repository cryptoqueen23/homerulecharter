# Historical charter versions

Empty on purpose.

One file per superseded charter version, named by the date that version took effect,
for example `1979-adopted.json` or `2018-11.json`. Each file uses the same shape as
`../current.json`.

Rules for this folder:

1. Only transcribed text goes in these files. Never a paraphrase, never a news
   description of what a section used to say.
2. A file here is evidence of what the charter said on a date. If you cannot name
   the source document and the date, do not create the file.
3. A difference between two versions is not proof that a section changed. It is a
   lead. The amendment record and the election ordinance are what establish a change.

Priority acquisitions are listed under `needed` in `../../sources/sources.json`.
