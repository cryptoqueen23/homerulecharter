Cove Charter WatchResearch Mode

Research mode

Build and edit amendment records offline, then export JSON to paste into the data files. Nothing here writes to a server, because there is no server.

Do not deploy this folder

Cove Charter Watch is a static site. Every file in the repository is fetchable by anyone who knows the URL. There is no login to add, because there is no backend to check one. If this folder ships to production, anyone can open it.

Two safe options. Keep research/ out of the deployed branch entirely and run it locally. Or deploy it and put a Cloudflare Access policy on the /research/* path so Cloudflare handles authentication before the file is served. Unpublished research notes belong in research-private/, which is gitignored and never deployed either way.
